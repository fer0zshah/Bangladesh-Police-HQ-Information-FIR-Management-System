# Bangladesh-Police-HQ-Information-FIR-Management-System

A comprehensive, database-driven management system designed for the Bangladesh Police force. This project serves as a centralized hub for managing officers, tracking criminal records, filing FIRs, and processing citizen complaints, with a strong focus on advanced relational database concepts.

## Core Modules & Features

* **Officer & Department Management:** Manage police personnel profiles, rank hierarchies, department assignments, transfer histories, and duty schedules.
* **FIR & Case Management System:** Register FIRs, assign investigating officers, track the complete lifecycle of a case, and log evidence and witness details.
* **Criminal Information Database:** Maintain detailed criminal profiles, wanted statuses, previous records, and enable advanced database-level search and filtering.
* **Citizen Complaint Portal:** A dedicated interface for citizens to submit general or emergency complaints online and track their resolution status.
* **Analytics & Role-Based Dashboard:** Separate secure access for Admins, Officers, and Investigators, featuring data-driven dashboards displaying active cases and crime statistics.

## Database Lab Focus Highlights

This project is built to demonstrate advanced database management concepts, specifically tailored for evaluation:
* **Complex Relationships:** Extensive use of `JOIN` operations across multiple normalized tables (e.g., linking Cases, Officers, Stations, and Criminals).
* **Advanced Queries:** Implementation of complex sorting, filtering, and aggregation for the analytics dashboard.
* **PL/SQL Integration:** (Upcoming) Utilization of Triggers, Procedures, and Functions to automate backend data handling, such as auto-updating case statuses and logging duty transfers.
* **Data Integrity:** Strict enforcement of Primary Keys, Foreign Keys, and unique constraints.
